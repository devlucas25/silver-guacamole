# Estrutura do Projeto

Este projeto está dividido em três componentes principais:

- `server/`: Contém a lógica de backend, incluindo modelos de dados, APIs e lógica de negócios.
- `mobile-app/`: Contém o código-fonte do aplicativo móvel do entrevistador.
- `admin-app/`: Contém o código-fonte do aplicativo de administração (web e móvel).
